About this tool

Polyflex Offcut Optimizer — version 1.0
Designed for semi-skilled operators to manage plate offcut stock without direct spreadsheet access.

The tool always works offline. When an API key is configured and the sheet is shared correctly, all searches and stock additions are automatically mirrored to the Google Sheet in real time.
